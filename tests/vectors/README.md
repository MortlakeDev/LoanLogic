# Golden test vectors (`tests/vectors`)

Golden vectors for the financial engine. The format and the comparison rules are
normative and defined in [`docs/SPEC-finance.md`](../../docs/SPEC-finance.md) §14; the
engine input they use is §15.

| Folder                    | Milestone | Content                                                                         |
| ------------------------- | --------- | ------------------------------------------------------------------------------- |
| [`core/`](core/README.md) | M1 (T02)  | schedules, fees, rounding, day count, rate metrics, validation                  |
| `events/`                 | M3 (T06)  | prepayments, rate changes, payment holidays, odd first periods — coming with R3 |
| `analytics/`              | M4–M5     | comparison, refinance, goal seek, affordability, deposits — coming with R4      |

## Format

```jsonc
{
  "schemaVersion": 1,
  "id": "e1-annuity-usd-24m",
  "description": "…",
  "source": "SPEC-finance §5.6 E1",
  "kind": "loan",              // or "cashflows"
  "input": { … },              // passed to the engine unchanged (SPEC §15)
  "expected": {
    "ok": true,
    "warnings": [],            // [{ "code" }], compared as a set
    "summary": { … },          // decimal strings, compared exactly
    "rates": {                 // value: percent; see "Comparison" below
      "usRegZApr": { "value": "6.500003564379", "display": "6.500", "precision": 3 }
    },
    "rows": [ { … }, … ]       // one schedule row per line
  }
}
```

Error vectors have `"expected": { "ok": false, "errors": [{ "code", "field" }] }`, compared
as a set. Cash-flow vectors (`kind: "cashflows"`, SPEC §9.7) have
`"expected": { "ok": true, "rates" }` or an error list.

## Comparison

- Decimal strings (money, dates) are compared exactly; `null` matches `null` or an
  absent field.
- A rate's `value` matches when the engine's unrounded percent lies within
  `max(1e-7, 1e-9 × |value|)` percentage points of it; `display` and `precision` must be
  equal; metric `warnings` are compared as a set (absent = none); a failed metric
  `{ "ok": false, "reason" }` must fail with the same reason. Every vector rate is at
  least ten tolerances away from a display boundary.

## Rules

- Generated by the reference implementation in [`tools/reference`](../../tools/reference)
  and checked with `python tools/reference/generate.py --check`. Never edit them by hand.
- Fields absent from a vector are not compared. M1 rows omit `interestCapitalized`,
  `extraPrincipal` and `penalty`, which must be zero; `explain` is never compared.
- The engine test harness loads every `*.json` file in a folder (not `README.md`).
