# Golden test vectors (`tests/vectors`)

Golden vectors for the financial engine, as defined in
[`docs/SPEC-finance.md`](../../docs/SPEC-finance.md) §14:

- Location: `tests/vectors/<area>/<id>.json` (for example `core/`, `events/`, `analytics/`).
- Shape: `{ id, description, source, input, expected: { summary, rows[], rates{} } }`.
- Ledger values are compared exactly as decimal strings; rates within 1e−6 percentage points
  before display rounding and equal after it.

Vectors are generated by the reference implementation in
[`tools/reference`](../../tools/reference) and by external sources. Do not edit them by hand.
